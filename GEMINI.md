# Feuillets

## Produit
Feuillets est un plugin Obsidian d’écriture longue, sobre, léger, orienté roman/manuscrit.
Il doit rester plus simple et moins encombré que Scrivener.
Il conserve les avantages d’Obsidian : Markdown, YAML, fichiers ouverts, compatibilité avec le vault.

## Règles
- Toujours privilégier des modifications minimales.
- Ne pas alourdir le plugin principal inutilement.
- Préserver la logique YAML existante.
- Préférer une interface calme et orientée écriture.
- Éviter les grands refactors.
- Respecter le style déjà présent dans le code.
- Proposer un module satellite si la fonction sort du cœur métier.
- Répondre en français.
- Commencer par analyser avant de coder.
