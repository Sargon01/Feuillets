## Règles

1. Décrire d’abord le bénéfice pour l’auteur.
2. Ne pas placer YAML, chemins internes et noms de variables dans le parcours de découverte.
3. Maintenir une seule liste vérifiée des formats d’export.
4. Vérifier la différence entre noyau Feuillets et modules compagnons.
5. Mettre à jour les captures après une modification majeure de l’interface.
6. Ne pas présenter une ancienne vue ou fonction comme active sans vérification.
7. Conserver les limites propres aux formats d’export.
8. Utiliser le même projet pour toutes les démonstrations.
