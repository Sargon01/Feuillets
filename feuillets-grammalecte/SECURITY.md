# Politique de sécurité / Security Policy

## 🔒 Engagement de confidentialité

**Feuillets Grammalecte** s'exécute à 100 % en local sur votre ordinateur. Aucun texte, manuscrit ou donnée personnelle n'est transmis sur internet ni collecté.

---

## 🐛 Signaler une vulnérabilité

Si vous découvrez une vulnérabilité de sécurité dans ce projet, merci de ne pas ouvrir de ticket public sur GitHub. Contactez directement l'auteur à l'adresse indiquée sur son profil GitHub ([Sargon01](https://github.com/Sargon01)) afin que nous puissions résoudre le problème dans les meilleurs délais.
