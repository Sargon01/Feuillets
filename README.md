# Feuillets

**Version française : [README-fr.md](README-fr.md)**

## Write first. Organize when the text needs it.

**Feuillets turns Obsidian into a writing and editorial studio for texts that may remain a single sheet or grow into a book.**

Write an article, short story, essay, chapter, collection or novel. Start in a blank Markdown file or in an Obsidian folder that already exists. Add structure only when the text needs it, then reread, compose and export one sheet, one folder, a selection or the entire project.

> **Text before system.**

Feuillets imposes no proprietary project format, narrative database or writing method. Your texts remain ordinary Markdown files and your folders remain real folders.

![Feuillets — writing and Preview](docs/feuillets-ecriture-apercu.png)

*Start by writing. Feuillets accompanies the text when it grows.*

## From one sheet to a book

Feuillets does not require you to decide at the beginning what a text will become.

### One text

A single sheet can be enough for:

- an article;
- a column;
- a short story;
- a short essay;
- a standalone chapter.

Write it, read it in Preview and export it on its own.

### Several texts

Several sheets can later become:

- a series;
- a folder;
- a short-story collection;
- a set of articles;
- a thematic collection.

Choose the texts, their order and separators without moving them into a special proprietary structure.

### A long project

When the work grows, Feuillets can progressively add:

- a hierarchical **Binder**;
- **Cards** and **Outline**;
- a visual **Notebook**;
- project **Research**;
- passage-aware **Context**;
- **Storyline** and **Timeline**;
- goals, statistics and a writing journal;
- snapshots, versions and backups;
- composition, export and editorial revision.

An article can remain an article. Ten articles can become a collection. A handful of scenes can become a novel. Feuillets does not require the destination to be known before the writing begins.

## Obsidian provides the environment; Feuillets provides the studio

Obsidian provides:

- the vault;
- Markdown;
- the editor;
- links and backlinks;
- Canvas;
- synchronization chosen by the user;
- the plugin ecosystem.

Feuillets adds the specialized writing tools:

- text organization;
- structural operations;
- Research and documentation;
- narrative views;
- rewriting and versions;
- composition and export;
- editorial revision return.

Feuillets does not replace Obsidian or create a second editor. It organizes the existing environment around the work of writing.

## Start without building a system first

### Turn an existing folder into a project

Any folder already present in the vault can become a Feuillets project **without moving, renaming or converting its personal files**.

For example:

```text
My texts/
├── Article.md
├── Column 2.md
├── Short story.md
└── Notes.md
```

With **Initialize as a Feuillets project…**, choose **Fiction**, **Non-fiction** or **Free**. The choice defines the initial tools and views; the existing organization stays intact. Feuillets adds its canonical auxiliary space around the texts:

```text
My texts/
├── Article.md
├── Column 2.md
├── Short story.md
├── Notes.md
└── _Feuillets/
    ├── Recherche/
    ├── Ressources/
    ├── Edition/
    ├── Journal/
    ├── Snapshots/
    ├── Backups/
    └── Sortie/
```

Legacy locations such as `_Recherche`, `_Research`, `Recherche`, `Research`, `_Ressources` or `_Resources` remain recognized when they already exist; Feuillets 2 does not automatically rename them.

### Create a new project

From the Binder welcome screen, create a **Fiction**, **Non-fiction** or **Free** project. The type only provides a starting structure:

- **Fiction**: `Front`, then `Chapitre 1/Scène 1.md`;
- **Non-fiction**: `Front`, then `Partie 1/Chapitre 1.md`;
- **Free**: only `Manuscrit/Nouveau texte.md`, with no imposed `Front`, part, chapter or scene hierarchy.

Feuillets 2 keeps auxiliary spaces under `_Feuillets` (`Recherche`, `Ressources`, `Edition`, `Journal`, `Snapshots`, `Backups`, `Sortie`). Some are created during initialization and others when they become useful. The type defines the first state; later choices remain yours.

## Write

A sheet remains an ordinary Markdown file opened in Obsidian's native editor.

Feuillets can provide:

- controlled text width;
- configurable typography and line height;
- prose-oriented paragraph indents;
- discreet Markdown syntax;
- French typography helpers when desired;
- manuscript-wide find and replace;
- footnotes and citations;
- typewriter scrolling;
- **Focus Mode**.

![Focus Mode](docs/feuillets-concentration.png)

The goal is not to put another interface between the writer and the text, but to remove interface when it is time to write.

## Think freely with the Notebook

The **Notebook** is based on an ordinary Obsidian Canvas.

You can:

- capture an idea without leaving the active sheet;
- add an existing sheet to the Notebook;
- move and group ideas freely;
- develop an **Idea Tree**;
- turn an idea into a sheet or Research note;
- create a chapter from a selection, group or branch;
- turn a branch into a Feuillets outline.

The Notebook helps you think. The Binder remains the real structure of the text.

An outline created from an Idea Tree can be re-imported later: Feuillets reuses existing items, preserves their order and adds only what is new.

**Advanced Canvas** is recommended for direct card menus and Idea Trees, but essential Notebook functions remain available without it.

See **[The Notebook — from ideas to manuscript](docs/HOW-TO-NOTEBOOK.md)**.

## Organize with the Binder

When structure becomes useful, the **Binder** can:

- navigate folders and sheets;
- create and rename items;
- drag items between folders or back to project root;
- multi-select;
- search titles or content;
- filter by status, label or progress;
- show excerpt, synopsis, summary, notes, tags, status or word count;
- open a file, folder or selection in Preview;
- compile a file, folder or selection.

![Binder](docs/feuillets-classeur.png)

*Structure remains available without becoming mandatory.*

## Several views of the same files

![Cards, Outline, Storyline and Timeline](docs/feuillets-mosaique-narrative.png)

| Need | View |
|---|---|
| Navigate through texts | Binder |
| Reorganize visually | Cards |
| Inspect information and progress | Outline |
| Follow narrative threads | Storyline |
| Check event order | Timeline |
| Read composed text | Preview |
| Explore freely | Notebook |

These views do not create parallel versions of the project: they show **the same files from different angles**.

## Inspector: information when it becomes useful

The right-hand Inspector contains five tabs that can be shown or hidden:

| Tab | Purpose |
|---|---|
| **Sheet** | Synopsis, summary, working notes, properties, footnotes and Context |
| **Research** | Documentation, characters, places, events, sources, bibliography and custom sections |
| **Journal** | Writing journal and tracking |
| **Edition** | Editorial documents and DOCX Revision |
| **Proofreading** | Native close-repetition signals and, when a companion provider is installed, additional linguistic findings |

Feuillets is progressively powerful: you can write with almost nothing visible, then open a tool only when it becomes useful.

## Research and Context

**Research** is available, not mandatory.

Depending on the project, it can contain:

- characters;
- places;
- events;
- concepts and lore;
- sources;
- bibliography;
- glossary;
- your own categories.

Inside **Sheet**, **Context** can connect the passage around the cursor with useful project information: explicit references, associated Research, related documents, chronological information and pinned items.

Matching remains **local and deterministic**. No remote AI analyzes the manuscript.

See **[Using Feuillets Context](docs/HOW-TO-CONTEXT.md)**.

## Rewrite without losing work

Writing also means moving, cutting, merging, starting again and sometimes going back.

Feuillets separates several tools:

- **snapshots** for a precise point of return;
- **comparison** to see changes;
- **versions** for exploring another direction;
- **ZIP backups** to protect project files.

![Compare two states](docs/feuillets-comparaison.png)

An as-is folder is backed up strictly within its own scope. A structured project whose active manuscript lives in `Manuscrit` backs up the parent project folder and its associated spaces.

## Preview, composition and export

**Preview** lets you leave the current fragment and read the composed result.

You can work with:

- one sheet;
- one folder;
- a selection of files and folders;
- the whole project.

Composition controls order, titles, separators, front matter and styles.

![Paginated Preview](docs/feuillets-apercu.png)

The native engine supports:

- **compiled Markdown**;
- **DOCX**;
- **EPUB**;
- **ODT**;
- **PDF** through desktop system printing.

Source Markdown is not modified by export.

## Work with an editor or proofreader

A DOCX exported by Feuillets can be sent to an editor or proofreader and returned with comments and tracked changes.

In **Edition → DOCX Revision**, Feuillets can:

- analyze returned feedback;
- map changes back to Markdown sheets;
- flag uncertain matches;
- accept or reject changes;
- preserve still-pending discussion;
- generate a revised DOCX.

The principle remains simple: **DOCX is an editorial exchange format; Markdown remains the source manuscript.**

See **[Review a Word manuscript with Feuillets](docs/HOW-TO-DOCX-REVISION.md)**.

## Import from Scrivener

On desktop, Feuillets can import a Scrivener project and recover compatible Binder structure, text, order and supported resources.

![Scrivener import](docs/feuillets-import-scrivener.png)

The imported project then lives as vault files and folders.

See **[Import a Scrivener project](docs/IMPORT-SCRIVENER-EN.md)**.

## Ecosystem

Feuillets keeps its core centered on writing and lets specialized domains evolve separately:

- **[Feuillets-Grammalecte](https://github.com/Sargon01/Feuillets-Grammalecte)** — French linguistic analysis;
- **[Courrier](https://github.com/Sargon01/Courrier)** — contacts, submissions, replies and follow-ups;
- **Advanced Canvas** — optional richer Notebook interactions.

## Freedom, privacy and security

- Markdown source files;
- ordinary folders;
- local operation;
- no telemetry;
- no manuscript upload to a remote service;
- no Pandoc dependency;
- GNU GPL-3.0 source;
- unminified, auditable production bundle;
- TypeScript, automated tests, ESLint and Obsidian review lint in CI.

Feuillets requires **Obsidian 1.13.0 or newer**. It is not declared desktop-only; PDF export is desktop-only because it uses the system print dialog.

See [PRIVACY.md](PRIVACY.md) and [SECURITY.md](SECURITY.md).

## Installation

### Obsidian Community Plugins

1. Open **Settings → Community plugins**.
2. Search for **Feuillets**.
3. Install and enable it.

### Manual installation

Download `main.js`, `manifest.json` and `styles.css` from the latest release and place them in:

```text
<your vault>/.obsidian/plugins/feuillets/
```

Reload Obsidian and enable Feuillets.
