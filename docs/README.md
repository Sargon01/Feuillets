# Documentation Feuillets / Feuillets documentation

Feuillets est un atelier d’écriture dans Obsidian. Les fichiers Markdown restent la source du manuscrit ; les vues, Carnets et outils de publication travaillent autour d’eux.

Feuillets is a writing workshop inside Obsidian. Markdown files remain the manuscript source; views, Notebooks and publishing tools work around them.
