# Importer un projet Scrivener

> **Français** · [English](IMPORT-SCRIVENER-EN.md)

## Changer d’atelier sans reconstruire le manuscrit

L’import Scrivener ne cherche pas seulement à récupérer un long texte.

Il vise à reprendre, selon les éléments compatibles :

- la structure ;
- les parties ;
- les chapitres ;
- les scènes ;
- l’ordre du manuscrit ;
- les contenus ;
- les synopsis ;
- les statuts et étiquettes ;
- les notes ;
- les images et ressources prises en charge.

## Pourquoi cela compte

Un projet peut représenter des années d’organisation. Un export en texte continu conserve les mots, mais détruit souvent :

- la hiérarchie ;
- les repères ;
- les synopsis ;
- les statuts ;
- les documents de recherche ;
- les choix de structure.

Feuillets cherche à éviter cette reconstruction manuelle.

## Après l’import

L’auteur peut reprendre le travail dans :

- le Classeur ;
- les Cartes ;
- le Plan ;
- l’Aperçu ;
- la Chronologie ;
- le Chemin de fer ;
- les outils de sauvegarde et de composition.

## Limite de plateforme

L’import Scrivener nécessite un accès au projet présent sur l’ordinateur. Il n’est donc pas proposé sur les environnements mobiles qui ne donnent pas cet accès.
