# Utiliser Feuillets à la place — ou à côté — d’Aeon Timeline

> Ce guide est volontairement nuancé : Feuillets possède une Chronologie orientée écriture, mais n’est pas un clone d’un logiciel spécialisé de modélisation temporelle.

![Cartes, Plan, Chemin de fer et Chronologie](feuillets-mosaique-narrative.png)

## La question à poser

Avez-vous surtout besoin de :

1. **vérifier la cohérence temporelle d’un manuscrit pendant l’écriture** ;
2. ou de **modéliser un univers temporel complexe comme une base dédiée** ?

Pour le premier besoin, Feuillets peut souvent suffire.

Pour le second, un outil spécialisé peut rester pertinent.

## Ce que la Chronologie Feuillets utilise

La Chronologie travaille à partir des mêmes données que le manuscrit :

- dates portées par les scènes/feuillets ;
- événements conservés dans Recherche ;
- ordre du Classeur ;
- informations de projet.

Elle peut ainsi confronter :

- **ordre narratif** : ordre de lecture ;
- **ordre chronologique** : ordre des événements.

## Événements de Recherche

La catégorie Événements peut être reconnue sous plusieurs noms historiques :

- Événements ;
- Events ;
- Chronologie ;
- Timeline ;
- Chronology ;
- `_Chronologie`.

Feuillets les réutilise lorsqu’ils existent au lieu de créer plusieurs rubriques concurrentes.

## Scènes et jalons

Une scène datée peut apparaître dans la lecture chronologique.

Des événements documentaires peuvent servir de jalons : guerre, naissance, voyage, changement politique, accident, etc.

Le but est de garder les données temporelles proches du texte qui en dépend.

## Contexte chronologique pendant l’écriture

La chronologie ne vit pas uniquement dans la vue dédiée.

Dans la section **Contexte** de Notes, Feuillets peut utiliser la date du feuillet et les données des fiches pour attirer l’attention sur des incompatibilités potentielles :

- personnage déjà mort ;
- personnage pas encore né ;
- état daté incompatible ;
- objet ou technique anachronique lorsque les données existent.

Ces alertes restent des aides. Elles n’éditent jamais le texte automatiquement.

## Chemin de fer et Chronologie ne répondent pas à la même question

Le **Chemin de fer** suit les fils narratifs.

La **Chronologie** suit le temps.

Les deux peuvent montrer la même scène mais selon deux axes différents.

## Quand Feuillets suffit généralement

Feuillets peut suffire si vous voulez :

- dater les scènes ;
- ordonner les événements ;
- visualiser les écarts entre narration et chronologie ;
- repérer des incohérences courantes ;
- garder les fiches historiques dans le même coffre que le manuscrit ;
- éviter une synchronisation manuelle entre deux bases.

## Quand garder un outil spécialisé

Un logiciel spécialisé peut rester préférable si votre projet exige par exemple :

- relations temporelles très complexes ;
- calendriers entièrement personnalisés ;
- contraintes de durée entre de nombreux événements ;
- modèles de causalité/relations très riches ;
- visualisation avancée multi-axes qui dépasse le manuscrit.

Dans ce cas, Feuillets peut rester l’atelier d’écriture et l’autre outil le modèle temporel de référence.

## Migration progressive

Si vous souhaitez réduire la dépendance à un outil externe :

1. commencez par dater les scènes importantes dans Feuillets ;
2. créez les principaux jalons dans Recherche ;
3. comparez ordre narratif et chronologique ;
4. utilisez Contexte pendant quelques chapitres ;
5. conservez Aeon en lecture seule le temps de vérifier que les informations nécessaires ont été reprises.

## Principe

Feuillets cherche à répondre à la question :

> **« Cette chronologie m’aide-t-elle à écrire et relire mon livre ? »**

Il ne cherche pas à gagner un concours de nombre de champs face à un logiciel de timeline spécialisé.
