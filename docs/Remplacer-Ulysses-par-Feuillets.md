# Passer d’Ulysses à Feuillets

> Guide de migration d’habitudes de travail.

Ulysses et Feuillets partagent une idée forte : l’écriture doit pouvoir rester simple à l’écran même lorsque le projet devient long.

Feuillets reprend cette simplicité dans Obsidian, tout en ajoutant une structure de manuscrit et des outils de Recherche/réécriture plus explicites.

![Écriture et Aperçu](feuillets-concentration-apercu.png)

## Correspondances

| Ulysses | Feuillets |
|---|---|
| Sheet | Feuillet |
| Groups | Dossiers du Classeur |
| Library navigation | Classeur + coffre Obsidian |
| Focused writing | Concentration |
| Keywords | Tags / labels selon le besoin |
| Goals | Objectifs |
| Preview | Aperçu |
| Export | Composition + export |

## 1. Les « sheets » restent naturelles

Le feuillet est proche de l’idée de feuille : une unité courte que l’on peut déplacer ou travailler seule.

Il reste cependant un fichier Markdown normal dans le coffre.

Vous pouvez choisir des fichiers très courts ou des chapitres entiers : Feuillets ne vous force pas à adopter une granularité particulière.

## 2. Retrouver une interface calme

Le mode Concentration masque l’environnement plutôt que d’inventer un éditeur séparé.

![Concentration](feuillets-concentration.png)

Pour un environnement proche d’un traitement minimaliste :

- gardez le Classeur compact ;
- masquez les informations de ligne inutiles ;
- cachez les onglets d’Inspecteur dont vous n’avez pas besoin ;
- ajustez largeur, police et interligne ;
- utilisez Concentration pour les séances de rédaction.

Voir [Créer une interface d’écriture épurée](SETUP-INTERFACE.md).

## 3. Le Classeur remplace la bibliothèque spécialisée

La hiérarchie de Feuillets est celle des vrais dossiers/fichiers.

Cela rend le projet moins abstrait : vous pouvez retrouver le manuscrit dans l’Explorateur Obsidian sans passer par Feuillets.

## 4. Du feuillet à la lecture continue

![Aperçu paginé](feuillets-apercu.png)

L’Aperçu permet de passer de l’écriture fragmentée à la lecture :

- du feuillet ;
- du dossier ;
- d’une sélection ;
- du manuscrit.

Le texte reste découpé sur le disque, mais la lecture peut être continue.

## 5. Objectifs et suivi

Les objectifs et compteurs permettent de retrouver un suivi d’avancement sans rendre les propriétés obligatoires.

Le Journal et les statistiques sont disponibles si vous souhaitez conserver une trace plus longue des séances.

## 6. Recherche plus structurée lorsque nécessaire

Feuillets peut aller plus loin qu’une simple bibliothèque de feuilles :

- fiches Personnages/Lieux/Événements en fiction ;
- Sources/Bibliographie en non-fiction ;
- rubriques personnalisées ;
- contexte autour du curseur ;
- documents associés.

Vous pouvez ignorer cette couche pour un texte court et l’activer seulement lorsque le projet l’exige.

## 7. Cartes et structure

Pour un manuscrit qui devient complexe, Cartes et Plan donnent une vision que l’écriture minimaliste seule ne fournit pas.

Le Chemin de fer et la Chronologie peuvent être ajoutés pour un roman sans modifier la manière dont les feuillets sont stockés.

## 8. Export

Feuillets compose les fichiers selon l’ordre du Classeur et la portée choisie.

Formats natifs :

- DOCX ;
- EPUB ;
- ODT ;
- PDF sur desktop ;
- Markdown compilé.

L’Aperçu permet de contrôler le résultat avant de produire le fichier.

## 9. Différence de philosophie

Le point le plus important n’est pas l’apparence.

Dans Feuillets :

- les fichiers vivent dans le coffre Obsidian ;
- l’éditeur reste celui d’Obsidian ;
- les fonctions spécialisées se superposent au Markdown ;
- un compagnon peut gérer la correction ou le suivi éditorial sans agrandir indéfiniment le noyau.

Si votre priorité est une bibliothèque intégrée fermée et extrêmement homogène, Ulysses peut rester plus simple.

Si votre priorité est de conserver vos textes dans un environnement Markdown extensible tout en retrouvant un vrai atelier de livre, Feuillets suit ce modèle.
